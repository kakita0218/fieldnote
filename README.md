# fieldnote

A new Flutter project.

## Current implementation

- ファイルアプリからPDFを選択して表示
- ピン配置・方向調整・6色のピンカラー
- Apple Pencilを想定した手書き、ペン色・太さ・消しゴム
- ピンごとのメモ・写真管理
- アプリ内カメラによる連続撮影
- 原本JPEGと表示用サムネイルを分けて保存
- 注釈付きPDF・写真ZIPの書き出し
- iPad横画面専用

On first run after this update, execute:

```bash
flutter pub get
```

Camera permission is configured for iOS and Android.

## 今回の追加機能

- 手書きとピンを反映した全ページPDFを生成
- ピン番号ごとの写真フォルダを3桁で生成（001、002、003…）
- 写真名をフォルダ内で3桁連番に統一（001.jpg、002.jpg…）
- PWAでは「現調図面.pdf」と写真フォルダを1つのZIPとしてダウンロード

## v6 ピン・ペンカラー改修

- 色：青・赤・黄・緑・紫・黒
- 通常ピンは小型ミニマル、選択ピンは丸バッジ強調
- 写真ありだけ外周リングで表示
- ピン／ペンの再タップで各設定を開く
- ツールアイコンは現在色を表示し、モード中は青い枠と発光を表示
- PDF出力はステータスなしの色付きミニマルピン

## v1.2 カメラ画面

- 右中央の大型シャッターボタン
- 右上に「ピン番号 / そのピンの写真枚数」
- 左下に最新3枚を横並び（最新は左）
- 撮影直後は最新写真が少し大きく表示され、約0.42秒で収まる
- 既存サムネイルは右へスライドして並び替わる
- カメラプレビューを止めず、原本保存を直列バックグラウンド処理
- シャッター音は固定で、設定項目は設けない
